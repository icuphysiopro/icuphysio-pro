Descarga directa

Android

Instala la aplicación mediante el archivo APK de la versión 1.0.2.

Escanea y descargaUsa la cámara de tu teléfono Android para abrir el enlace de descarga.
Descargar APK para Android

Cómo instalar

  1. 01Descarga el APK usando el botón o el QR.
  2. 02Abre el archivo descargado desde tu dispositivo.
  3. 03Si Android solicita permiso para instalar desde esta fuente, revisa el origen del archivo y autoriza únicamente si confías en él.
  4. 04Completa la instalación y abre ICUPhysio PRO.

Acceso desde navegador

iPhone y iPad

Abre la versión web en Safari y añade un acceso directo a tu pantalla de inicio.

Escanea y accedeAbre el enlace en Safari desde tu iPhone o iPad.
Abrir versión web

Cómo añadir a inicio

  1. 01Abre el enlace en Safari.
  2. 02Presiona Compartir (cuadrado con flecha hacia arriba).
  3. 03Selecciona «Añadir a pantalla de inicio» (la ubicación puede variar según la versión de iOS).
  4. 04Confirma con «Añadir» para crear el acceso directo.
